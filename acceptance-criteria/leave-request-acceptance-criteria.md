# Leave Request — Acceptance Criteria

These acceptance criteria apply to the core leave request submission and approval workflow.

- The employee can select a leave type from a predefined list.
- The employee can enter a start date and an end date.
- The employee can provide a reason for the leave request.
- The system calculates and displays the number of leave days requested.
- The request is routed to the employee's assigned manager.
- The employee receives confirmation once the request has been submitted.
- The manager can approve or reject the request.
- The employee is notified when the request status changes.
- The system prevents submission of overlapping leave requests for the same employee.
