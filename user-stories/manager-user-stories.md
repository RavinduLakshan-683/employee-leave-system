# Manager User Stories

## US-MGR-001
As a manager, I want to review leave requests submitted by my team so that I can decide whether to approve or reject them.

## US-MGR-002
As a manager, I want to approve a leave request so that the employee can proceed with their planned leave.

## US-MGR-003
As a manager, I want to reject a leave request with a reason so that the employee understands why it was not approved.

## US-MGR-004
As a manager, I want to see how many leave days my team members have remaining so that I can plan team coverage.
