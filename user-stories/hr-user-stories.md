# HR User Stories

## US-HR-001
As an HR administrator, I want to configure leave types so that the organisation's leave policy is reflected in the system.

## US-HR-002
As an HR administrator, I want to set and adjust employee leave balances so that entitlements are accurately tracked.

## US-HR-003
As an HR administrator, I want to generate leave reports so that I can review organisation-wide leave trends.

## US-HR-004
As an HR administrator, I want to manage user roles and permissions so that access to leave data is properly controlled.

## US-HR-005
As an HR administrator, I want to cancel an approved leave request when required so that exceptional circumstances can be handled.
