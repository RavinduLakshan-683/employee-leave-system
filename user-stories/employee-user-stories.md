# Employee User Stories

## US-EMP-001
As an employee, I want to submit a leave request so that I can obtain approval from my manager.

## US-EMP-002
As an employee, I want to view the status of my leave requests so that I know whether they have been approved or rejected.

## US-EMP-003
As an employee, I want to view my remaining leave balance so that I can plan future leave requests.

## US-EMP-004
As an employee, I want to cancel a pending leave request so that I can correct mistakes before it is reviewed.

## US-EMP-005
As an employee, I want to view my previous leave requests so that I have a record of my leave history.
